# Novai Mod v3.6.1 (Minecraft 1.21.1 — Fabric + Fabric API)

Обновление **v3.6.1** для **Minecraft 1.21.1** на загрузчике **Fabric** с использованием **Fabric API**.

---

## Что нового в обновлении `v3.6.1`

1. **Спавн случайного Креативного Оружия за прохождение Испытания**:
   - Теперь сразу после успешного выживания в 5-минутном проклятом Испытании прямо в воздухе перед выжившим игроком в ударе молнии и вихре частиц **спавнится случайное креативное оружие** (парит в невесомости с яркой подсветкой, неуязвимо к лаве/взрывам и никогда не деспавнится, пока вы его не подберёте!):
     - *«Клинок Разлома Реальности»*, *«Маяк Орбитального Лазера»*, *«Катаклизм Геоманта»*, *«Зеркало Повелителя Миров»*, *«Жезл Небесной Кары»*, *«Сфера Сингулярности»*, *«Хроно-Скипетр»* или *«Око Бескрайности»*.

   - Существует **строго в 1 экземпляре на весь мир** (`ОСТАЛОСЬ ВСЕГО: 1 шт.`) и продаётся **только в микрозайме** у Элитного антиквара МФО за **`14 990 ₽`** (без крафта, огнеупорный и защищённый от изъятия).
   - По нажатию **ПКМ** открывает меню выбора живых игроков на сервере и позволяет за **`1 000 ₽`** со счёта за каждое перемещение:
     - телепортироваться **к выбранному игроку** («К игроку»), или
     - телепортировать **выбранного игрока к себе** («К себе»).

## Сборка мода

Требуется **JDK 21**:
```bash
./gradlew build
```
Готовый файл мода появится в `build/libs/novaimod-3.5.0.jar`. Поместите его в папку `.minecraft/mods` вместе с **Fabric API** для версии **1.21.1**.
